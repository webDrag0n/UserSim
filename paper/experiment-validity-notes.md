## 二、思路整理：这是 Experiments 章节的效度论证大纲

六条笔记可归并为**四个论证模块**，恰好补齐 introduction_v2 中 RQ1–RQ3 的实证设计：

### 模块 A · 判别力 Sanity（①②③ → RQ1/RQ2）

论证 benchmark "是一杆秤"：先证明秤能区分轻重，再谈称出了什么。

| 实验 | 对应矩阵 | 预期结论（预先注册的 sanity 断言） |
|---|---|---|
| 固定双侧 harness，横评模型 | E1 | 分数随模型档位单调：弱模型显著弱、强模型显著强（档位来自 LMArena 等外部榜单先验） |
| 固定模型，横评 assistant harness | E2/E3 | harness 间有区分度：reference 为参考线，外部 harness（openclaw/hermes）落位有上有下，不挤成一团 |

- 与现有设计的关系：①② 是已知组效度检验（known-groups validity；reference vs stub 阳性/阴性对照，Cohen's $d>1.5$）的**推广**——从"两个对照组"扩展为"全榜单单调性"；③ 即 E2/E3 矩阵的判别力验收。
- ⚠️ ③ 的另一种解读：reference 应高于 openclaw/hermes（即参考实现应赢过外部样例）。**两种读法含义不同，需与笔记作者确认**：前者是"有梯度即可"，后者是"reference 必须是上界"。

### 模块 B · 评测有效性：规则打分 vs 人类 vs LLM judge（④）

笔记中划掉了"让人标哪个 trace 是哪个 assistant"的图灵式识别测试，改为**三方对比论证**，逻辑链是：

1. **人类金标准自身不可靠**：让真实用户对 trace 表现排序 → 排序方差很大（标注者间一致性低）→ "与人工排序算 Kendall's τ"这条传统效度路径的根基是噪声；
2. **LLM judge 可复现性差**：把同一批 trace 扔给强模型（Claude Fable 5）评分/排序 → 记录其结论；
3. **我方主张**：0-LLM 规则打分（轨迹的确定性函数）**更稳定**（重算方差为 0、跨版本不漂移）且**更准确**（不混淆文风与实质，直接锚定状态真值）；辅以 trace check（正确性检查）验证轨迹本身的合法性。

- 与 introduction 的关系：这正式取代了附件版中虚构的"Pearson r / Kendall τ 人工满意度相关性"——效度论证从"我们与人相关"转向"**人本身就不可靠，我们比人和 LLM 都稳**"。这是更强的立场，且完全可执行。
- 实验成本：人类排序只需小样本（目的是证明方差大，不是建立金标准）；LLM judge 一次过；规则打分零成本。

### 模块 C · 用户模拟效度与 Reward Hacking 防御（⑤ → RQ3）

两个子主张：
1. **trace 拟人性**：用户 agent 的行为轨迹符合正常人类模式——落点是 M1–M5 操纵检验（manipulation check）+ 拟人化指标（习惯化曲线、需求动力学、峰终/消极偏向，docs/11），可补充真人对照（人类对被试 trace 的拟人度评分，或直接放 trace 让人判断"像不像真人"，注意与模块 B 的人类实验复用标注资源）；
2. **防刷**：助手得高分必须来自真实的状态控制，而非 reward hacking——规则指标锚定世界真值 $\mathbf{x}$，对话文本不进评分，助手无从"演"出高分；旁注"成本低"指规则打分相比 LLM judge 的边际成本≈0，可大规模复算。

### 模块 D · 子指标能力归因（⑥）

总分之外的诊断价值——benchmark 不只排名，还能回答"差在哪"：

- 按子指标族拆解：控制族（$e_{ss}, t_s, M_p$, IAE/ISE/ITAE）、观测族（$\|\mathbf{x}-\hat{\mathbf{x}}\|$ 学习曲线、画像精度）、行为族（求助及时性、打扰率、契约违约率）→ 对每个 agent 画能力画像；
- **记忆能力的专门验证**：reference vs reference_nomem 消融是直接证据——同一模型、只差记忆结构，若 $\hat{\mathbf{x}}$ 估计误差与控制指标显著退化，即证明 benchmark 能"评测出记忆能力"；这也是 E2 矩阵存在性的最有力论据。

## 三、对论文叙事的三个影响

1. **Experiments 章节骨架确定**：5.1 判别力 sanity（模块 A）→ 5.2 评测有效性三方对比（模块 B）→ 5.3 用户效度与防刷（模块 C）→ 5.4 主榜横评 + 子指标归因（模块 D + E1/E2/E3 跑分表）。
2. **效度论证的"对手"变了**：不再是"与人工标注对齐"，而是"人类方差大、LLM 漂移、我们稳定且锚定真值"。Related Work 中 LLM-as-judge 一段的批判因此有了直接实验支撑，intro 第 2 段的"其三"可以在实验章节闭环。
3. **新增两个待执行实验**：(a) 人类小样本 trace 排序一致性研究；(b) Fable 5 作为 LLM judge 的对比评分。两者都不依赖主跑分，可提前并行做。
