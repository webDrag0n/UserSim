# 1. Introduction（重写版）

LLM 驱动的个人助手正在从"一次性问答工具"转变为"长期伴随式智能体"：它需要在数周乃至数月的跨度里记住用户、理解用户、在恰当的时机介入、在不该打扰时保持安静。然而主流评测体系仍停留在短 horizon 范式——静态问答集测知识，单 episode 任务 benchmark 测工具调用与任务完成率——它们都无法回答产品决策者真正关心的问题：**这个模型（或这套 agent 架构）能不能在长达一个月的持续交互中始终"懂"它的用户？** 长程能力（记忆、用户建模、干预时机、行为一致性）的缺口不在于模型做不到，而在于缺少一把能量它的尺子。

现有评测范式在长程场景下存在三条结构性失效路径。其一，**静态数据集**：真实对话是树状的——不同性格的用户对同一句话会做出不同回应，对话在每一轮都可能分叉；而数据集是一条预设的线，轮次加长后实际轨迹必然偏离脚本，评测随之失效（图：单线 vs 分叉树）。其二，**短任务交互 benchmark**（τ-bench 一类）：它们把评测从"判答案"推进到"跑 episode"，但终局信号仍是单任务完成率——测得了"这一次任务成没成"，测不了"一个月里用户状态被维护得好不好"；且稀疏的 0/1 终局信号让失败归因（credit assignment）无从下手：错在第 3 天的错误记忆，还是第 20 天的过度打扰，无从分辨。其三，**LLM-as-judge**：对对话文本打分牺牲了可复现性——judge 模型自身在漂移，文风与实质被混为一谈，同一轨迹换个 judge 版本结论就变。

本文的关键主张是：**不要读对话，去模拟用户。** 我们把"助手协助用户维持良好状态"形式化为一个闭环稳态控制（homeostatic control）问题：纯规则世界持续产生扰动 $d(t)$（加班、应酬、天气突变），将用户的四维内部状态 $\mathbf{x}$（心情、精力、饱腹、压力）推离设定点附近的"平和带"；恢复行为 $u(t)$ 是控制量，但其时机与质量由助手的建议驱动——助手是控制器，用户是带人格的执行机构。如此，模糊的"用户满意度"被转译为一组可计算的控制论量（稳态误差、调节时间、超调量、带内驻留比）；稀疏终局信号被替换为逐时段的稠密真值轨迹，credit assignment 从"猜"变成"查"——失败可以被定位到具体的维度、时段与事件。

基于这一形式化，我们实现了 UserSim，一个长程用户–助手模拟与 benchmark 系统，其设计由一条边界约束：**世界 0 次 LLM 调用，LLM 只存在于两个 agent 内**。用户状态的唯一写入方是规则结算器，用户 agent 只负责把状态"表达"为言行（状态–表达解耦）；助手 agent 每轮必须输出对用户状态与人格的结构化估计 $\hat{\mathbf{x}}$——"理解用户"从隐含能力变为强制观测项；评估器只消费结构化日志、从不读对话文本，因此全部指标是轨迹的确定性函数，可离线重放、完全可复现。世界由种子确定性生成；被测件经统一 agent 接口接入，模型与 agent 架构（harness）可分离评测；每次 run 落盘 artifact 哈希与 prompt 版本作为复现凭证。

我们把"测量仪器自身的效度"当作一等设计问题，而非事后补实验。用户模拟器是这台仪器的探头：其人格一致性由 5 项规则指标（M1–M5）构成质量门——门不过，助手分数不可信；benchmark 的判别力由 live 锚点对（reference vs stub）的量程守护断言（Cohen's $d > 1.5$）；跨模型结论一律以多 seed 均值 ± 95% CI 与最小可检测效应（MDE）报告，杜绝"差 0.5 分排第 3"的伪排名。

我们围绕三个研究问题展开：**(RQ1)** UserSim 能否稳定区分助手能力的高低（量程与判别力）？**(RQ2)** 固定 harness 横评模型（E1）、固定模型横评 harness（E2/E3）时，排名结论分别是什么、彼此是否一致？**(RQ3)** 用户模拟器的人格一致性与真人对齐度如何——它作为测量仪器是否可信？

**贡献**：
1. **形式化**：将 user–assistant 长程交互建模为闭环稳态控制问题，给出"世界扰动—用户状态—助手控制—观测器估计"的完整动力学与指标体系，把长程评测从文本评判转为轨迹测量；
2. **系统**：UserSim benchmark——种子确定性世界、状态–表达解耦、0-LLM 规则评估器、统一 agent 接入接口与完整可复现性凭证；
3. **效度方法论**：测量仪器效度的分层评估框架（用户一致性质量门 M1–M5、量程守护、MDE 统计报告）；
4. **实证**：基于 E1/E2/E3 评测矩阵对 [N] 个模型与 [M] 种 harness 的多 seed 横评结果与分析。

就我们所知，UserSim 是首个以闭环控制形式化 user–assistant 长程交互、并以零 LLM 规则评估器给出完全可复现轨迹指标的 benchmark 系统。

1. 差异化叙事（为什么别人要关注你）

现有榜单全是静态题：饱和、被训练数据污染、测不出"长程"。你的卖点是**"30 天交互式情绪稳态控制"**——唯一测"模型能不能在一个月里持续把用户维持在平和带内"的榜单。交互式 + 种子化世界，天然抗刷题，这个故事本身就值钱。
一句话 headline："静态跑分测智商，UserSim 测情商与耐心——谁能在 30 天里不出错。"
