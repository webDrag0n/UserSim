## Introduction

LLM-powered personal assistants are shifting from one-shot question-answering tools to *long-horizon companion agents*: systems that must remember their users, understand them, intervene at the right moment, and remain silent when intervention is unwarranted, over weeks or even months of continuous interaction (Park et al., 2023; Zheng et al., 2025). Mainstream evaluation, however, remains anchored in short-horizon paradigms. Static question-answering suites probe knowledge or long-context memory over frozen transcripts (Maharana et al., 2024; Wu et al., 2024), while single-episode task benchmarks measure tool use and task completion in executable environments (Liu et al., 2023; Jimenez et al., 2023; Zhou et al., 2023a). Although the task-completion horizon of frontier agents is growing rapidly (Kwa et al., 2025), none of these paradigms answers the question that product decision-makers actually face: *how accurately and efficiently can we evaluate user satisfaction for an agent engaged in long-term, continuous interaction?*

To study this question quantitatively, we decompose it further: an assistant should progressively learn a user's profile and preferences through sustained contact, and provide advice and assistance in the most efficient way possible. Evaluating such long-horizon behavior requires four entities — a **world**, a **user**, the **assistant under test**, and a **judge**. We treat the world and the user as a single coupled dynamical system whose state evolves over time. Under this abstraction, existing evaluation paradigms can be positioned along two axes: how the world is constructed, and how the user is constructed (Figure 1). The most faithful feedback naturally comes from the real world and real human users, but the cost of human-in-the-loop longitudinal studies is prohibitive (Kapoor et al., 2024). What is needed is a simulation of the world–user dynamics that is simultaneously credible and cost-effective.

Surveying existing paradigms through this lens exposes a structural gap. **Static dataset paradigms** (Maharana et al., 2024; Wu et al., 2024; Jiang et al., 2025) can only measure behavior on single turns or fixed trajectories: a frozen question set repeatedly pulls the assistant back onto a prescribed path, making it impossible to observe the distribution drift and closed-loop intervention effects that arise in real deployments (Li et al., 2026). **Executable real-world environments without a user** (Liu et al., 2023; Jimenez et al., 2023; Zhou et al., 2023a) offer verifiable dynamics but reset after every episode and contain no persistent user state at all. **LLM-driven simulation** — using a language model to play the user inside an otherwise rule-based world, as in τ-bench (Yao et al., 2024) and its successors, or to generate social dynamics wholesale, as in generative-agent sandboxes and lifelong social benchmarks (Park et al., 2023; Zhou et al., 2023b; Goel et al., 2025) — restores interaction but introduces a black box into the measurement loop: recent fidelity studies show that freely role-playing LLM users are systematically unrealistic, exhibiting formality ceilings, directive amplification, over-compliance, and a failure to disengage, with success rates fluctuating by several points purely as a function of the simulator model (Zhu et al., 2026; Anonymous, 2026a; Anonymous, 2026b). The same black-box problem afflicts LLM judges, whose scores suffer from position bias, self-enhancement, version dependence, and error accumulation over long evaluation chains (Gu et al., 2024). Finally, **rule-based game-like simulations** (Carroll et al., 2019; Shridhar et al., 2020) provide controllable and measurable internal dynamics, but their episodes last minutes, their rules are deliberately narrow rather than end-to-end, and none of them models an endogenous *user need* that persists across a lifetime.

We therefore propose an entropy-inspired, rule-based simulated world paired with an LLM-based *human proxy*, designed so that controllability lives in the rule layer and naturalness lives in the language layer. The core logic draws on homeostatic regulation rather than literal thermodynamics: the world acts as a dissipative environment that continuously pushes the simulated user's internal state away from its stable set points — the user gradually becomes hungry, fatigued, and bored — while the user's objective is to collaborate with the assistant to schedule activities that restore equilibrium. This design instantiates, in an evaluation setting, the classical two-resource formulation of homeostatic control in which internal variables incur deficits over time and must be held within a viability band (Keramati and Gutkin, 2014; Anonymous, 2024). Crucially, the human proxy's *needs* are generated by the rule layer: the proxy can perceive its state-induced needs and form intentions to resolve them, but — like a real person — it has no internet access and does not know which places or activities are available. The assistant's role is precisely to close this information gap through search and scheduling. Because the underlying motivation is rule-generated and statistically observable, our human proxy sidesteps the fidelity pathologies of freely role-playing LLM users documented by Zhu et al. (2026): the LLM never owns the user's goals, it only verbalizes them. We operationalize user satisfaction as the fraction of time the user's state dwells inside the homeostatic band, and measure six key capabilities of the assistant: (i) the dwell-time ratio of the user state within the stable band; (ii) the accuracy of the assistant's learned user profile; (iii) the learning speed of that profile; (iv) the accuracy of need comprehension; (v) the conflict-free rate of proposed schedules; and (vi) the pass rate of schedules against basic rule checks.

This design yields a judge system for free. Existing judging schemes inherit the same trilemma as world simulation: human annotation is too expensive, and LLM judges of long-horizon behavior are opaque, weakly interpretable, and still costly (Gu et al., 2024; Kapoor et al., 2024). Because our world–user dynamics are rule-based, user satisfaction can be modeled as a closed-loop steady-state control (homeostatic control) problem: dwell time within the stable band and schedule success are directly enumerable from state trajectories, and profile/need accuracy can be computed per episode against the rule-layer ground truth, yielding error curves whose convergence, convergence speed, and asymptotic error can be analyzed without any model in the loop (Figure 3). On the cost–fidelity spectrum (Figure 1), our framework occupies the vacant middle ground between human-in-the-loop studies and LLM-free-form simulation: game-like controllability with life-like horizons.

Our contributions are:

* **An entropy-inspired rule-based simulation world** with endogenous, controllable, and statistically observable user-need dynamics, supporting closed-loop evaluation over week-to-month horizons;

* **A control-theory-inspired, state-grounded judge system** that derives dwell time, profile/need error curves, and schedule success directly from rule-layer ground truth, requiring no LLM judge at any stage;

* **A plug-and-play agent interface with accompanying skill documentation**, enabling arbitrary LLM assistants to be mounted and evaluated with minimal engineering effort.
