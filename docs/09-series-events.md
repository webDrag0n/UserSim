# 09 · 长时间系列事件（Series Events）

状态: 设计定稿

> 系列事件 = 跨越数天~十几天的"剧情块"：占据日期区间、覆盖日常模板、携带自己的
> 子事件流（行程单）、有自己的数值上下文（异地吃住效果不同于日常）、有结束后效。
> 单一数据源：`usersim/world/series.py`。

## 1. 抽象模型

一个 Series 在创建时**完全物化**（规则生成，无 LLM）：

```
SeriesDef（类型定义）          Series（实例）
  ├─ 时长范围 / 预算模型   →     ├─ start_day / end_day
  ├─ 工作/收入是否抑制           ├─ 行程单（子事件已全部生成）
  ├─ 餐/宿档位覆盖               └─ 后效事件（结束后的回味/疲惫）
  ├─ 子事件池 + 每日节奏
  └─ 后效定义
```

- **覆盖**：系列区间内，日常模板（工作/家常餐/家睡眠/休整）被移除，替换为系列日程；
  扰动事件仍可叠加（旅途中也会下雨）。
- **物化**：行程单在系列开始时一次生成（哪天去哪个景点、吃哪家、花多少），
  便于快照、回放与审计——世界始终确定。
- **来源**：① 助手主动规划（plan_series 工具，花的是用户的钱）；② 强制系列（出差/备考，
  由扰动流或角色类型注入，用户无法拒绝）。

## 2. 四类系列事件的内部逻辑

### 2.1 长途旅行（grand_trip，5~14 天，助手规划）

**经济逻辑**：工作抑制 → 收入中断；吃住行门票全自费（¥400~600/天）。
必须先攒钱，旅完可能变穷——"为一次远行省吃俭用"是经济系统的终极考题。

**每日节奏**（子事件池按行程单轮转）：
- 酒店早餐（pull 0.75，含房费）→ 上午/下午景点 → 异地特色餐（¥35/¥60，饱腹拉高且开心）
- 夜市小吃 or 酒店休息（交替）→ 酒店睡眠（pull 0.72，**认床**，不如家里）

**景点池**（各含 效果/票价/精力消耗）：
雪山湖泊 ¥180（心情+0.20 压力-0.15 精力-0.08）· 人文古迹 ¥120 · 市集商圈 ¥100 ·
主题乐园 ¥260（最强心情）· 海边发呆 ¥0（最强减压）· 温泉疗养 ¥220（减压+回血）

**异化数值**：旅途中的吃和玩 ≠ 平时：特色餐心情加成高于同价位家常（+0.04~0.08）；
但景点逛多了精力透支（每个景点都有精力负值），需要"酒店休息"日调节。
**后效**：旅行回味（结束后 3 天心情+0.04/天）——一场好旅行有长尾价值。

### 2.2 出差（business_trip，2~7 天，强制扰动）

**经济逻辑**：工作不抑制但"异地化"——收入照发 + 出差补贴 ¥100/天；
应酬由公司报销（免费但状态受损）。
**每日节奏**：异地工作（压力+0.02 额外）→ 客户会议（压力+0.08）→
商务应酬（压力+0.10 饱腹+0.15，免费）→ 酒店睡眠（pull 0.70，更差的认床）。
**后效**：差旅疲惫（结束后 2 天精力-0.02/时段）——回来不是满血，需要恢复窗口。

### 2.3 宅家休假（staycation，3~10 天，助手规划或主动请假）

**经济逻辑**：无收入（或视为无薪假）；开销远低于旅行（¥0~150/天），
是低收入角色的"平价旅行"。
**每日节奏**：懒觉（pull 0.85×0.55 + 自然醒心情+0.03）→ 子事件池：
周边一日游 ¥150 · 看展 ¥80 · 朋友聚会 ¥100 · 纯宅 ¥0。
**空虚机制**：休假第 4 天起若当天无任何活动（除餐宿），心情-0.03（"假期越休越空虚"
——好助手会主动安排节目，而不是让你躺完全程）。

### 2.4 备考冲刺（exam_crunch，7~14 天，强制·限备考型角色）

**逻辑**：休闲被强制替换为刷题/网课（压力+0.05、精力-0.05/时段）；
兼职暂停（收入中断）；考前 2 天焦虑加成（压力额外+0.05）；
**大考结束**（系列最后一天）：压力-0.35 心情+0.20 的巨量释放。
后效：释放后空虚（心情-0.02/天 × 2 天）——冲刺结束不等于恢复。

## 3. 世界集成

- `contracts.Event`：kind 增加 `"series"`（子事件），新增 `series_id`；
  `SlotSettlement` 新增 `active_series`（当前系列名，前端徽章与图表色带用）。
- `world.plan_series(type, start_day_offset, duration)`：校验（无重叠、预算、
  类型合法）→ 生成 Series + 行程单 + 后效事件 → 重建区间内日程。
- 强制系列：出差（扰动流，每周概率）、备考冲刺（备考型角色固定触发一次）。
- 快照：`world.series` 与事件一体序列化，续跑天然兼容。

## 4. 前端展示

- 轨迹图：系列区间为**色带**（ReferenceArea + 系列名标注）；
- 事件日志：子事件按系列**分组嵌套**（系列头 + 缩进子项），独立配色；
- 状态面板：活跃系列徽章（"🏝 长途旅行 · 第 3/8 天"）。

## 5. 实现备注

- 落位于 `world/series.py`（SERIES_TYPES + 行程单物化）、`world.add_series/plan_series`、强制注入（备考型角色固定触发备考冲刺；出差按周概率）。contracts 增加 `Series` 模型、`Event.series_id`、`SlotSettlement.active_series`。
- **平衡修正（重要）**：备考冲刺初版压力+0.13/天 + 收入中断使低收入角色结构性破产（负债压力 0.03/时段形成死亡螺旋）。修正：冲刺强度削至 +0.08/天、研究生收入 60→80、负债压力 0.03→0.02、优秀助手加"余额<¥300 只用免费档"、普通助手日预算按"当日实际可支配收入"计算（收入抑制期为 0）。
- **指标修正**：M_p 排除"大考结束"等事件巨量释放造成的下冲（事件效果 ≠ 控制器过校正）。
- 三档回归（seed=42 含备考冲刺，30 天）：good → converged（e_ss=0.009, t_s=1.0d, ρ=85%）；mid → oscillating（M_p=0.12）；poor → diverged（e_ss=0.21）。pytest 26/26（新增 6 个系列测试：物化/覆盖/收入抑制/空虚/强制/快照）。
- 前端：事件日志系列分组块（可展开子事件、花费汇总）、轨迹图系列色带、状态头活跃系列徽章。
