# 11 · 拟人化行为系统（习惯化曲线 + 需求动力学 + 数值单一数据源）

状态: 定稿（经两轮设计评审）

## 0. 现状行为分析（缺陷清单）

当前用户模拟的行为机制及其非人之处：

| # | 现状 | 非人之处 |
|---|---|---|
| A1 | 事件效果是**固定向量**，每次执行全额生效 | 楼下公园连去 10 次每次都 -0.10 压力——真人会腻（习惯化） |
| A2 | 无任何"上次做这件事是什么时候"的记忆 | 真人隔几天再去会觉得新鲜（恢复/间隔效应） |
| A3 | 需求=状态维度，求助触发只看扰动/压力阈值 | 真人的行为由多种需求（饥饿/社交/刺激/成就）共同驱动，且各有动力学 |
| A4 | 心情只向 v_eq 线性耦合 | 真人情绪有不对称性：坏事比好事更持久（消极偏向）；还有峰终定律 |
| A5 | 人格（大五）是冻结摆设，不影响任何效果 | 内向者社交耗电、外向者社交回血——同一事件对不同人效果不同 |
| A7 | 人格只有 5 个域分，喜好只是一段自由文本 | 粒度太粗且无法量化估计精度——已在 `docs/13-persona-model.md` 升级为 30 facet + 结构化喜好 |
| A6 | 数值散在 catalog.py + Excel 导出物（单向） | 调参要改代码；Excel 只是报表不是数据源 |

## 1. 习惯化与恢复（边际效益曲线）

### 1.1 机制

- 世界维护 `last_done: dict[规范事件名, t_logical]`（快照序列化）。**无计时器**——结算时用 `Δt = t_current - t_last` 查曲线。
- 每次事件结算时：`effect_effective = effect_base × w(Δt)`，随后更新 `last_done[name] = t_current`。
- 权重曲线（每动作独立参数，非直线）：

```
w(Δt) = 1 - (1 - w_min) · curve(Δt)
curve_exp : exp(-Δt / τ)          # 指数恢复（大多数人/事）
curve_sqrt: (Δt / (Δt + τ))^0.5   # 快恢复慢饱和（社交类）
curve_s   : Δt² / (τ² + Δt²)      # S 型（深度爱好：刚隔不久也还不错，很快回满）
```

- 参数：`w_min`（连续重复时的效果下限，即习惯化深度）、`τ`（恢复时间常数，单位：时段）。
- Δt=0（同一时段连续做同一件事）→ w = w_min；Δt→∞ → w→1。
- **作用域**：recovery 事件 + 自定义活动 + 系列子事件中的"活动类"（景点/聚会等，餐宿不参与——吃饭睡觉不腻烦）。
- 类别共享：`文化看展` 与 `自定义活动·看展` 共享同一个规范键（用归一化后的规范名作为 last_done 键，天然统一）。

## 2. 需求动力学（Needs & 认知动力学曲线）

在状态向量之上加一层**需求层**（四个基本需求），每个需求有独立的**驱动力曲线**与**满足曲线**，不都是单调的——对齐人类认知动力学。

### 2.1 需求定义与动力学

| 需求 | 累积 | 满足事件 | 驱动力曲线 u(x)（→求助倾向） | 满足曲线 s(x)（→效果权重） |
|---|---|---|---|---|
| 饥饿 hunger | satiety ↓ → hunger ↑ | 吃好吃的/三餐 | u = clip((1-x)/0.6)^1.5（低饱腹加速） | s = 1 + 1.5·u（越饿吃得越香） |
| 社交 social | 每时段 +0.01（外向者 ×1.6） | 朋友小聚/应酬 | u = x²（温和平方增长） | s = 1 + 0.8·u |
| 刺激 stimulation | 单调事件 -，新异事件 + | 看展/旅行/新地方 | **倒 U：u = 1 - (2x-1)²**（太少无聊、太多过载） | s = 0.6 + 0.8·(1-u_mid)，过刺激时效果打折 |
| 成就 achievement | 临近考试/截止 ↑ | 刷题/工作推进 | u = x^2.5（后期陡增，deadline 效应） | 完成时 valence 释放 ∝ x |

- 需求状态 n ∈ [0,1]，每时段由规则更新（累积/消退），进快照。
- **求助驱动**：`session_urge = max_i u_i(n_i)`；world 的 idle 介入点概率改为 `idle_prob × (0.3 + 0.7·session_urge)`——需求越强越容易开口，而非固定概率。
- **效果调制**：恢复/自定义事件的对应维度效果 × 满足曲线 s(x)。
- **非单调关键点**：刺激需求的倒 U 曲线使"连轴转的高刺激日程"（旅行塞满景点）也会产生过载烦躁——valence 扣减，这逼助手安排"留白"。

## 3. 峰终定律与消极偏向

- **峰终定律**（系列后效）：系列结束时记录 `peak_valence` 与 `end_valence`，后效强度 = 0.5·peak + 0.5·end 相对基线的差值（替代固定后效向量），正负皆可（糟糕的旅行回味为负）。
- **消极偏向**：心情耦合速率不对称——v_eq < valence（变差）时速率 ×1.5，v_eq > valence（变好）时 ×0.7。坏事消化得慢。

## 4. 人格调节（大五生效）

- **社交电池**：社交类事件（朋友小聚/应酬）的 energy 效果 × (1 - 0.6·外向性/100)——内向者耗电更多；外向者（>70）额外 valence +0.03。
- **神经质**：压力事件效果 × (1 + 0.5·神经质/100)；均值回归速率 × (1 - 0.4·神经质/100)。
- **开放性**：文化看展/新异刺激效果 × (0.7 + 0.6·开放性/100)。

> **已升级为 facet 粒度**（`docs/13-persona-model.md` 第 1.2 节）：社交电池改读
> 外向性.群居性、心情加成改读 外向性.热情、压力放大与回归改读 神经质.焦虑+脆弱、
> 新异刺激改读 开放性.尝新+审美。域分作为 facet 缺失时的回退（旧存档行为不变）。
> 另新增**喜好调节**：恢复/系列事件的正向效果 ×(1 ± 0.4·类目偏好分)。

## 7. 设计评审记录

### 评审 1（一致性与既有系统冲突）

- **Q**: 习惯化会不会让脚本 good 失稳（控制目标变移动靶）？
  **A**: 恢复效果下限 w_min≥0.15 保证最低回血能力；good 的策略是"选执行后误差最小"，习惯化改变候选效果值，策略自动适应（选更大档或换动作——这正是想要的拟人行为：换着花样玩）。
- **Q**: 需求层与已有 staycation boredom 重复？**A**: boredom 规则删除，由刺激需求倒 U 统一承担。
- **Q**: 快照兼容？**A**: `last_done`、`needs` 加入快照，缺省为空 dict/初始值，旧存档可续跑。
- **Q**: 确定性？**A**: 全部查表/公式，无新随机源。

### 评审 2（性能与可测性）

- **Q**: 性能？**A**: 无计时器，全部 O(1) 查表；事件结算仅多一次 dict 查找。
- **Q**: 曲线参数进 Excel 后代码默认与表不一致的风险？**A**: 启动日志打印生效来源（excel/default）；测试用代码默认，Excel 加载单独测试。
- **Q**: 需求层会不会与状态维度重复记账？**A**: 需求只驱动"求助倾向/效果权重"，不直接改状态；状态仍只由事件/动力学写入（第一公理不破）。
- **Q**: 非单调倒 U 导致助手无法收敛？**A**: 倒 U 只影响 valence 小权重项且刺激满足事件本身有上限（每天活动数有限），不破坏可控性；回放三档判定回归为验收。

定稿：无待办改进项，进入实现。

## 8. 实现备注

- **引擎**：`world/anthro.py`（习惯化曲线 + 需求动力学 + 人格调节）；`world._effective_events` 在结算前对活跃事件做 习惯化×满足曲线×人格 的效果变换；餐宿/工作/学习不参与习惯化。
- **需求层**：只驱动求助倾向（idle/meal 介入点概率按 urge 门控）与效果权重，不直接写状态（第一公理不破）；staycation 旧 boredom 规则已删除，由刺激需求倒 U 统一承担。
- **峰终定律**：`world._series_track` 记录系列峰值/末值心情，结束时一次性冲量（±0.15 封顶）。
- **消极偏向**：心情耦合速率不对称（变差 ×1.5 / 变好 ×0.7）。
- **曲线修正**：sqrt/s 衰减核方向在初版写反（dt=0 未达 w_min），已修正为 c:1→0。
- **神经质调节压力回归**（第 4 节承诺项）：初版 `reversion_rate_mult` 定义了但从未被调用——
  该承诺实际未生效。第七轮已接入 `dynamics.settle_slot(reversion_mult=...)`，由 world 按
  persona 的大五传入（神经质 15 → ×0.94，神经质 90 → ×0.64）。
- **Excel 单一数据源**：`balance-sheet/UserSim数值配表.xlsx` 11 张表；`world/balance.py` 加载 习惯化曲线/需求参数/人格调节/恢复事件/扰动/经济参数 覆盖代码默认（效果串解析器支持 `心情+0.06` 与 `饱腹→0.70(×0.75)` pull 格式）；导出脚本改为"缺失才初始化"保护用户编辑。
- **配表编辑器**：前端顶级页面，7 张可编辑表，单元格点击即改、回车保存并热加载（POST /api/balance/cell）；习惯化曲线 w(Δt) 与需求 u(x)（含倒 U）实时预览。
- **测试**：35/35（新增 8 个拟人化测试：曲线端点/形状、重复递减与间隔恢复、刺激倒 U、社交电池、饥饿满足、快照兼容）。
- **回归**：good 收敛（带内 85%）/ mid 振荡（40%）/ poor 发散；Excel 热编辑（w_min 0.5→0.45）即时生效验证。
