# 08 · 事件配表与经济系统（基础+档位加权模型）

状态: 已实现

> 单一数据源：`usersim/world/catalog.py`。Excel 配表由脚本从同一份数据导出：
> `python scripts/export_balance_sheet.py` → `balance-sheet/UserSim数值配表.xlsx`（6 张表）。

## 1. 数值哲学（对标游戏数值平衡配表）

### 基础效果 + 档位加权

每个事件都有**基础效果**（base_effect）——任何档位都能拿到：

> 吃饭都能吃饱；休息都能回点精力；出门都能解点压。

每个档位有**加权**（weight）——这档预算在各维度上的分配方向：

> 楼下快餐虽然能吃饱（base: 饱腹+0.25）但不会很开心（weight 只给 心情+0.02）；
> 收藏多年的小店把预算大幅加权到心情与减压（心情+0.20 压力-0.10）。

**合计效果 = base + weight**，结算时按 span 摊销（pull 类除外）。

### 进餐与睡眠也是事件

不再是全局动力学参数，而是配表档位：

- 进餐：M0 随便对付（饱腹只拉到 0.55，不开心）/ M1 日常家常 ¥10（模板默认）/ M2 品质外卖 ¥25
- 睡眠：S0 熬夜浅睡（精力上限 0.55，惩罚档）/ S1 正常睡眠（默认）/ S2 高质量睡眠 ¥50（pull 0.88×0.6 + 额外降压）

日常档进模板日程并产生每日生活开销（¥10×3）；可被助手/用户升级（工具参数只需名称，别名表兜底口语措辞）。`pull` 类效果 = 拉向准稳态（目标×速率），不按时长摊销。

### 收入按职业分档

| 职业 | ¥/工作时段 | 特征 |
|---|---|---|
| 高压互联网从业者 | 260 | 高薪高压 |
| 自由插画师 | 130 | 收入不稳 |
| 备考研究生 | 60 | 只有兼职，免费恢复是主力 |
| 初创公司创始人 | 320 | 最高 |
| 倒班护士 | 190 | 中等 |
| 远程程序员 | 230 | 中高 |

低收入角色让经济约束成为难度维度：同样的扰动流，研究生必须精打细算，创始人可以花钱买状态。

## 2. 世界裁决规则

1. **世界只信查表数值**：LLM 自报效果对目录内事件无效；别名表把口语措辞（"早睡""散步""火锅"）映射到配表变体。
2. 目录外自定义活动：限幅 ±0.35 且免费；未自报效果时给规则默认值（{心情+0.06, 压力-0.05}——"做喜欢的事总是有点用"，数值由规则定）。
3. 金钱不足则高价安排被拒（工具结果失败，LLM 可见并会降级选择）。
4. 金钱扣除在事件首个活跃时段；负债（金钱<0）每时段 +0.03 压力。

## 4. 对 Agent 策略的影响

- **脚本助手**（回放）：good = 最小化执行后预测误差 + 反弹区惩罚（最优一拍控制）；mid = 比需求大 30% + **日预算护栏**（当日恢复开销 ≤ 日收入×60% + 存款×5%——超调但不破产）；poor = 只买最便宜的。
- **LLM 助手**：prompt 内置目录、余额感知（每轮注入当前余额）与分档干预决策规则（压力>0.6 必须选强减压选项等）。

## 5. 调参记录（本轮新发现）

1. **破产螺旋**：mid 在低收入角色上"单笔不超余额一半"仍会连续购买当天烧光 → 破产 → 负债压力 → 误差单调上升被误判发散。修复：日预算模型。
2. **判定指标抗噪**：端点斜率在振荡轨迹上会把正常波动误判为发散 → 发散判据改为"后 5 天均值 vs 前 5 天均值的持续恶化对比"（端点斜率保留为信息项）。
3. **LLM 目录命中率**：自由措辞大量漏配 → 别名表 + 地点模糊匹配 + 默认效果兜底。
4. **过度节俭**：助手看不到余额时倾向全选免费档，状态崩了钱还在涨 → 每轮注入余额 + 分档干预决策规则。

## 6. 回归状态

- 规则回放（seed=42，30 天）：good → converged（e_ss=0.009, t_s=1.0d, ρ=88%）；mid → oscillating（M_p=0.24）；poor → diverged（e_ss=0.26）。种子 7 / 2026 抽查 good 均收敛。
- pytest 20/20 全绿（含经济测试：职业收入、配表裁决、支付能力、负债压力、自定义限幅与默认值）。
- 真实 LLM（DeepSeek 参考 Harness）为朴素基线：在低收入的困难剧本上倾向发散——这是基准线的测量意义所在；强 Harness 的改进空间正是 benchmark 要量化的。
