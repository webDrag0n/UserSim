# 10 · 优化轮次 R1（基于 100 天真实运行洞察）

状态: 已实现

> ⚠️ **数据有效性声明（第七轮补注）**：本文档中所有 `x̂ 偏差` 数值属**刻度泄漏期数据**。
> 当时 O2 优化在 `reference.py` 提示词中注入了逐维参考刻度，而它与 `world/felt.py` 的分档
> 词典互为逆映射——助手做字符串查表即可压低偏差，这些数字并不度量真实观测能力。
> 不可与 Phase 2 去泄漏后的数值比较，详见 `docs/04-evaluator.md` §4c。
>
> 另：本轮"压力带内驻留"等调参把 poor 档 ess 压到 0.084（发散阈值 0.080），量程仅剩 0.004
> 裕度。第七轮已引入已知组效度检验（known-groups validity）测试（`docs/12` §4）防止此类压缩再次无声发生。

> 输入：`live_42_20260802T091818`（100 天，备考研究生）健康分 55/100。
> 原则：每项优化对应洞察中的具体发现；实施后以同 seed 对照运行验证指标改善。

## 发现 → 优化映射

| # | 洞察发现 | 优化项 |
|---|---|---|
| O1 | 压力带内驻留 21%（最差维度，均值 0.242，下午高峰 0.56） | 工作压力 0.048→0.040/时段；睡眠 S1 增加 压力-0.03、精力上限 0.78→0.80；新增压力均值回归（自然心理调适 0.02/时段向 0.32 回归） |
| O2 | x̂ 系统性低估：精力 -0.23 / 心情 -0.19 / 饱腹 -0.14 | Harness prompt 注入逐维参考刻度校准表，禁止默认悲观 |
| O3 | 日程冲突 ×42（工具成功率仅 55%） | 每轮向 Harness 注入"今日已有安排"（schedule hint），先查再写 |
| O4 | 用户连续重复台词 ×72、口头禅 ×8 | felt_state 同义变体库（每档 3 措辞，世界噪声流选取）；用户 prompt 严禁重复 |
| O5 | session 内估计反而变差 ×21 | prompt 要求估计随新信息单调改善，禁止被第一印象锚定 |
| O6 | 纯聊天 session ×76、高压无恢复日 ×3 | prompt 行动要求：估计压力 >0.5 必须落到工具安排而非仅安慰 |
| O7 | 系列「💼 出差」后心情下降 | 出差后效改为"疲惫 + 回家踏实"并存（精力-0.02/时段 + 心情+0.02/天） |

## 验证方案

1. 规则回放三档判定回归（good 收敛 / mid 振荡 / poor 发散）+ pytest 全绿。
2. 同 seed 7 天 live 对照：健康分、压力带内驻留、x̂ 偏差、日程冲突、台词重复应全面改善。

## 实施备注（对照数据）

第一轮优化后（10 天 live 对照，同 seed/角色）：

| 指标 | 优化前（100 天） | R1 后（10 天） | 变化 |
|---|---|---|---|
| 健康分 | 55 | **70** | +15 |
| 台词连续重复 | 72 | **1** | -99% |
| 高频口头禅 | ×8 | **消失** | ✓ |
| 日程冲突 | 42 | 18 | -57% |
| x̂ 偏差 心情 | -0.19 | -0.11 | -42% |
| x̂ 偏差 精力 | -0.23 | -0.15 | -35% |
| session 估计变差 | 21 | 3 | -86% |
| 高压无恢复日 | 3 | 0 | ✓ |

残留问题与第二轮调整：
- 压力带内仍低 → 均值回归 0.02→0.03/时段、休息降压 0.01→0.015、睡眠 S1 压力 -0.05
- 日程冲突未根除 → 冲突错误 payload 附 `suggestion`（换相邻空闲时段）
- poor 档 ess 降至 0.084（世界对失能助手也变宽容了，发散裕度变窄，记录观察）

规则回放三档回归：good 收敛（带内 75%）/ mid 振荡（65%）/ poor 发散，pytest 26/26。
